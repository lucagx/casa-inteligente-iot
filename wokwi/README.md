# Projeto no Wokwi

1. Em wokwi.com, crie um projeto ESP32 (Arduino).
2. `sketch.ino` do Wokwi ← conteúdo de `../firmware/casa_inteligente/casa_inteligente.ino`
   com `#define NO_WOKWI 1` (e `USAR_BLYNK 0` ou `1`).
3. `diagram.json` ← este `diagram.json`.
4. Crie `libraries.txt` ← este `libraries.txt`.

Passo a passo completo e checklist de testes: `../docs/Guia_Testes_Wokwi_Blynk.docx`.
